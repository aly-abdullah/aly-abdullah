## Aly Abdullah

Senior Full-Stack .NET Developer based in Saudi Arabia. I have spent the last eight years building web systems with C#, ASP.NET Core and SQL Server, most recently for government and higher-education organizations, with Angular on the front end.

### What I work on

- **Secure access platforms**: a gate-access system for government facilities, designed from scratch, with fingerprint verification and multi-factor authentication.
- **Case management and live dashboards**: nationwide case-management workflows with real-time dashboards and integrations with national information services.
- **Performance and delivery**: tuning systems that handle millions of records, and setting up CI/CD pipelines with monitoring.
- **Paper-to-digital workflows**: more than ten systems that replaced paper processes with scheduling, digital archiving and multi-tenancy.

### Stack

- **Backend:** C#, ASP.NET Core, Web API, Entity Framework Core, ADO.NET, SignalR
- **Frontend:** Angular, TypeScript, HTML, CSS
- **Data:** SQL Server, query and schema tuning, stored procedures
- **Delivery:** Azure DevOps, Azure, IIS, Microsoft Entra ID, Grafana
- **Desktop:** WPF, Windows Forms
